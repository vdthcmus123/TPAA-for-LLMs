# Raw dataset provenance

`MRBench_V1.json` was downloaded from:

https://raw.githubusercontent.com/kaushal0494/UnifyingAITutorEvaluation/main/MRBench/MRBench_V1.json

Repository: https://github.com/kaushal0494/UnifyingAITutorEvaluation

Paper: Maurya et al. (2025), *Unifying AI Tutor Evaluation: An Evaluation
Taxonomy for Pedagogical Ability Assessment of LLM-Powered AI Tutors*, NAACL.

The raw file is kept unchanged. Normalized data belongs in `data/processed/`.

The MRBench repository README states that MRBench is released under CC BY-SA
4.0 because it builds on MathDial and Bridge. Cite the MRBench paper and check
the upstream dataset terms before redistributing any adapted dataset.
